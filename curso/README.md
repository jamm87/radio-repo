# Curso de Radioaficionado — Temario HAREC

Curso para la preparación del examen de obtención del diploma de operador de
estaciones de radioaficionado en España (certificado **HAREC**, conforme a la
Recomendación **CEPT T/R 61-02**).

El temario sigue el programa oficial del **Anexo II de la Orden IET/1311/2013**.

> **Atribución:** este curso reutiliza y adapta el contenido del proyecto de
> código abierto **[eaharec.com](https://eaharec.com)** (licencia MIT).
> Repositorio original: **[github.com/t00mas/eaharec](https://github.com/t00mas/eaharec)**.
> Todo el mérito del contenido original corresponde a sus autores; aquí se
> presenta adaptado a formato Markdown para su estudio y edición.

## Información del examen

- **Duración:** 90 minutos
- **Formato:** test por ordenador en la JPIT provincial
- **Aprobado:** 50 % en cada parte, de forma independiente
- **Resultado:** certificado HAREC (CEPT T/R 61-02)
